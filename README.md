# PRASANN (प्रसन्न) — starter website

A responsive, static HTML/CSS/JavaScript starter using the supplied PRASANN logo and Kaju packet image.

## Run locally
Open `index.html` in a browser. No build step is needed.

## Publish
This is static frontend code. Host it only on a service whose terms permit your intended business use. Before publishing, check the host's current acceptable-use and commercial-use rules. A custom domain such as `prasann.in` is optional and usually costs money to register.

## Important limitations (please read)
- Registration in this starter is a **front-end demo**. It stores the entered number only in the visitor's browser via `localStorage`; it does **not** send numbers to the owner or create a central customer list.
- The registration screen is not identity verification; there is no OTP.
- There is no real admin dashboard, admin authentication, media upload, stories backend, database, or central order history yet. Those need a backend/database/storage service and secure authentication.
- Do not collect or rely on customer phone numbers for business until a proper privacy notice, secure storage, access controls, and applicable legal requirements are addressed.
- Kaju Shape Snacks are described as maida-based kaju-shaped snacks, not actual cashews.
- Prices included for Kaju Shape Snacks: 150g ₹60, 300g ₹110, 500g ₹180. Other prices were not provided, so customers are asked to enquire on WhatsApp.
- The WhatsApp contact is set to 8448047203. Change `WHATSAPP_NUMBER` in `script.js` if needed; use country code without `+`.
- Product photos for Mathri, Namak Paare, and Mixes are temporary graphic placeholders, not real product photos. Replace them with your own product photos before launch.
